📖 Project Overview

LISSO is an open-source, minimalist productivity hub tailored for students, freelancers, and remote professionals. It seamlessly unifies a dedicated Focus Room with comprehensive Task Management, local Note-taking, and temporary P2P Video Meeting Rooms into one fluid, single-page browser experience.
Built with a strict offline-first, zero-AI, and no-tracking philosophy, LISSO respects your cognitive bandwidth and your data security. No sign-ups, no logins, and no servers required.

🎨 Design Philosophy & Themes

LISSO relies on a warm minimalist UI featuring rich, subtle linen textures and hyper-clean layouts engineered to mitigate digital fatigue. It includes multiple meticulously tuned theme palettes accessible via the settings panel:
• 🪻 Cyber Iris – Deep, cybernetic neon accents over smooth dark backdrops.
• 🌌 Obsidian Noir – True OLED black scaling designed for late-night programming sessions.
• 🍵 Emerald Zen – Calming, organic botanical green shades to lower stress levels.
• 🪵 Warm Amber – Earthy, classic low-contrast tones reminiscent of physical high-end stationery.
• 🏔️ Nordic Glacier – A crisp, stark minimalist high-latitude monochrome approach.
• 🌹 Neon Rose – Punchy modern aesthetic contrast accents for vibrant daytime workflows.

🚀 Key Functional Modules


🧭 1. The Focus Room

A dedicated distraction-free canvas built to shield you from external platform notifications.
• 25-Minute Sprint: A strict manual countdown timer designed for pure deep work execution.
• Zen State Mode: Hides all surrounding navigation, sidebars, and trackers, leaving only an aesthetic full-screen digital clock.
• Granular Time Adjusters: Easily bump sessions on the fly via discrete +1m, +5m, +15m, and +25m control pads.

🎧 2. Procedural Soundscape Engine

Rather than streaming heavy background media tracks, LISSO uses the native browser Web Audio API to procedurally synthesize low-overhead audio waves locally in real time:
• 🌧️ 48kHz Rain Ambience: Organic, mathematical layer mimicking soft structural precipitation.
• 🧋 350Hz Brown Noise: A deep, resonant low-frequency rumble built specifically to anchor focus for ADHD and highly sensitive minds.
• 🌸 1/f Pink Noise: Balanced spectral density tailored to smooth out harsh ambient room environments.
• 🧬 6Hz Theta Induction: True-stereo panned binaural beats engineered to coax your neural state into relaxed concentration.
• 🔗 External Inputs: Supports pasting standard YouTube track URLs or streaming local .mp3/.wav assets directly through the browser layer.

📝 3. Auto-Sorted Task & Project Pipeline

Ditch manual list rearrangements. LISSO structures your workflow natively through structural parameters:
• The Priority Stream: Tasks are automatically grouped and pushed dynamically down an urgent execution vector (High → Medium → Low).
• Project Milestone Anchors: You cannot create empty project backlogs. Creating a project strictly forces a project description and an initial active metric task.
• Time Tracking Context: Filters split your immediate focus fields between All, Today, Upcoming, and Completed categories.

📊 4. GitHub-Style Analytics & Gamification

Track your work routines entirely locally through private behavioral mapping:
• 28-Day Heatmap: A visual density matrix color-scaling according to your actual daily task output metrics.
• Daily Streak Engine: Live monitoring loops tracking continuous execution windows.
• Velocity Telemetry: Clean weekly velocity charts computing task completion speed without reporting metric datasets back to third-party trackers.

📝 5. Scratchpad & Document Workspace

• Autosave Rich Text Editor: Instant local text persistence layer protecting scratch notes from unexpected browser reboots.
• Document Explorer: Monitors active live word counts and allows exporting content instantly to raw .txt files.

🤝 6. Peer-to-Peer Meeting Rooms

Need instant syncs without creating bulky calendar events or room links?
• Deterministic Join Paths: Spin up web-RTC audio/video calls using rapid 10-digit numerical meeting IDs.
• Decentralized Media Stream: Encrypted WebRTC technology coordinates peer-to-peer data pipes without cloud storage interception.
• Hardware Blocks: Granular, immediate physical webcam pauses and microphone mutes, plus an inline collapsible text chat window.

🛠️ Architecture & Tech Stack
 
• Core Engine: Vanilla HTML5, CSS3 Custom Properties, and ES6+ JavaScript. No bulky frameworks.
• Acoustics Engine: Native Web Audio API executing real-time mathematical signal generation.
• Communication Layer: WebRTC for browser-to-browser media coordination.
• Data Privacy: Client-side local storage. Zero telemetry, zero cookies, zero external databases.

⚠️ Framework Limitations & Rules

To maintain high architectural integrity, the project strictly excludes certain features by design:
• No Automated Break Loops: Pomodoro tracking requires intentional, manual interaction. The app will never automatically start break periods or trigger unexpected timers.
• No Eisenhower Matrix Layouts: Task structure is built on a single unified linear priority stream, intentionally eliminating 4-quadrant layout clutter.
• Zero Artificial Intelligence: LISSO functions as a pure deterministic tool. It does not parse, read, or process your written text files with automated machine-learning models.
