# LISSO Workspace

**LISSO** is a free, minimalist, online productivity workspace and focus timer designed to bring calm and clarity to your daily workflow. Developed by **Think Sprint**, it integrates essential tools—such as a countdown focus timer, priority-sorted task lists, project planning, notes, and instant peer-to-peer meeting rooms—into a single, unified browser environment. 

Built with a **zero-AI, privacy-first architecture**, all your tasks, notes, documents, and productivity analytics stay completely local on your device. **No sign-up, no tracking, and no subscriptions required.**

---

## 🌟 Key Features

### 1. Focus Room & Generative Acoustics
* **25-Minute Focus Sprints:** Simple countdown timer built for Pomodoro-style flow (with +1m, +5m, +15m, +25m adjustment intervals).
* **Zen State / Fullscreen Mode:** Hides all distracting workspace UI, leaving only the aesthetic clock.
* **Client-Side Soundscapes:** In-browser generation of 48kHz bandpass rain, 350Hz rumble brown noise, 1/f curve pink noise, and 6Hz theta induction binaural beats.
* **External Audio Streaming:** Stream custom YouTube background music or upload local audio files directly.

### 2. Auto-Sorted Task Stream
* **Priority Sorting:** Tasks are automatically ordered strictly by priority level: **High → Medium → Low**.
* **Tab Filters:** Quickly toggle view states between All, Today, Upcoming, and Completed.
* **Milestone Anchoring:** Bind deadlines directly to your calendar grid to avoid timezone slippage or bloated backlogs.

### 3. Purposeful Project Tracking
* **Deliverable Validation:** Creating a project requires a description and at least one initial task to prevent empty, unstructured backlogs.
* **Progress Tracking:** Monitors project milestones alongside daily task execution.

### 4. Interactive Analytics & Heatmaps
* **28-Day Activity Heatmap:** A GitHub-style intensity calendar calculated purely from completed tasks.
* **Daily Streak Tracker:** Live telemetry monitoring consecutive active focus and completion days.
* **Weekly Velocity:** Analytics visualising daily output trends without external server tracking.

### 5. Quick Notes & Rich Documents
* **Autosaving Text:** Local, client-side scratchpad for fast data capture.
* **Document Library:** Track word counts and download written specifications directly as `.txt` files.

### 6. Peer-to-Peer Real-Time Meetings
* **Instant Collaboration:** Create audio/video rooms or join using a secure 10-digit numeric ID without cloud lock-in.
* **Hardware & UI Control:** Native microphone mute, camera pause toggles, and a collapsible live side chat.
* **Host Security:** Only room creators have rights to delete active rooms.

## 🛠 Tech Stack & Architecture

* **Frontend:** Clean UI featuring warm linen textures, minimalist layout styling, and global accent theme switching (Cyber Iris, Obsidian Noir, Emerald Zen, Warm Amber, Nordic Glacier, Neon Rose).
* **Audio Synthesis:** Native **Web Audio API** engine executing browser-side synthesis for real-time sound layering.
* **Data Storage:** **100% Client-Side Privacy** using browser local storage; zero telemetry, zero cookies, and zero external database reporting.
* **Utilities:** Integrated command shortcut navigation (`Ctrl + K` global search bar).

## 🚀 Getting Started

Since LISSO is an offline-first, browser-based web application, setup requires no installations or account setups.

1. Visit the live platform at **[lisso.vercel.app](https://vercel.app)**.
2. Set up your local profile (Name and Profession/Role) on the onboarding modal. *Note: This data never leaves your computer.*
3. Launch your focus timer, generate acoustics, and start structuring your workload securely.
